| 1 | 홈 | 메뉴 카드 둘러보기 | 다시 운전대를 잡는 당신을 위해 / 네 가지 연습 메뉴 |
| 2 | 자동차 기능 | 시동·깜빡이·기어 번호 누르기, 기어 P·R·N·D, SUV vs 세단, 경고등 | 자동차 기능 알아보기 |

| 5 | 주행 | 자동 운전 스크립트(키 입력 흉내)로 초급 코스 완주, 직선 구간 3배속 | 출발 / 횡단보도 / 우회전 / 신호등 / 도착 / 주행 결과 |
| 6 | 주차 | 직각 후면 주차 → 시범 보기 | 주차 연습 / 시범 보기 |
| 7 | 법규 퀴즈 | 빠른 퀴즈 2문제 정답 + 해설 | 법규 퀴즈 52문제 |
| 8 | 휴대폰 화면 | 모바일 크기 홈·기능·주행(화면 버튼) | 휴대폰 · 태블릿에서도 |
| 끝 | 엔딩 카드 + QR 엔딩 12초 | – | 다시 운전 |

**이번에 배운 점**
- 공개 사이트가 정적 사이트(진도는 브라우저 localStorage)라 로컬 서버 없이 공개 주소로 바로 녹화 가능
- 운전 장면은 사람이 조작할 수 없으므로 `drive_autopilot.js` (화살표·Q/E/D/P 키 입력만 흉내) 로 주행
  - 바깥 차로가 연석에서 1.75m 뿐이라, 우회전은 교차로 안까지 들어가서 핸들을 끝까지 꺾는 방식이어야 함
  - 신호등은 정지선 1m 전에 멈추도록 거리 기반 감속, 황색은 못 멈추면 통과, 적색 우회전은 하지 않고 녹색 대기
  - 보행자·신호가 무작위라 점수가 매번 다를 수 있음 → 자막은 실제 점수를 읽어 표시
- 탑승 점검의 브레이크 상태는 시동 단계에서 이어지므로 기어 단계에서 브레이크를 다시 누르면 오히려 풀림
- 긴 대기·직선은 게임 시간을 3배로 돌리고 화면에 "▶▶ 3배속" 표시
